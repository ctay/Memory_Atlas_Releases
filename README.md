# Memory Atlas — versions publiées / releases

**Français** — Ce dépôt ne contient que les versions publiées de Memory Atlas, application macOS de description archivistique (ISAD(G)) d'Oorun : les images disque (`.dmg`) signées et notarisées, et le flux de mises à jour (`appcast.xml`) lu par l'app. Le code source n'est pas public.

Téléchargez la dernière version dans [Releases](https://github.com/ctay/Memory_Atlas_Releases/releases/latest). Chaque version indique l'empreinte SHA-256 de son image disque. L'app vérifie elle-même la signature des mises à jour.

**English** — This repository only holds the published releases of Memory Atlas, Oorun's macOS app for archival description (ISAD(G)): signed and notarized disk images (`.dmg`) and the update feed (`appcast.xml`) the app reads. The source code is not public.

Download the latest version from [Releases](https://github.com/ctay/Memory_Atlas_Releases/releases/latest). Each release lists the SHA-256 of its disk image. The app verifies the signature of updates itself.
